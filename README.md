# Hotel Booking System (HBS)

Hệ thống đặt phòng khách sạn trực tuyến và quản trị buồng phòng - đồ án môn học PRN222 (FPT University).

- **Hồ sơ chi tiết dự án:** Vui lòng xem tài liệu đầy đủ tại [PROJECT_OVERVIEW.md](PROJECT_OVERVIEW.md).
- **Nhật ký AI / RBL Audit Log:** Xem tại [AI_Audit_Log.md](AI_Audit_Log.md).

## Khởi chạy nhanh

### 1. Backend (ASP.NET Core 8 Web API)
```bash
cd HotelBooking
dotnet run
```
API Swagger UI: `http://localhost:5191/swagger`

### 2. Frontend (React 19 + Vite 6)
```bash
cd frontend
npm install
npm run dev
```
Giao diện người dùng: `http://localhost:3000`
